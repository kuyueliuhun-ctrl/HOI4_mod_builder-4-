## 1. H4MPS 审查

- 公开渠道（GitHub 仓库搜索、Bing/DDG 精确搜索、变体搜索）查无 "H4MPS" → 大概率是内部/未公开工具、拼写变体或误称。
- 若意图是「对 HOI4 mod 做语法/规范审查」，标准答案：
  - **CWTools**（[cwtools/cwtools](https://github.com/cwtools/cwtools)）：F#/.NET，Clausewitz 脚本语言解析/编辑/校验；HOI4 规则在 [cwtools-hoi4-config](https://github.com/cwtools/cwtools-hoi4-config)；配套 [cwtools-vscode](https://github.com/cwtools/cwtools-vscode)（LSP 语言服务）与 [cwtools-action](https://github.com/cwtools/cwtools-action)（GitHub Action，`game: hoi4` 输出 `output.json`）。
  - **HOI4-Validator**（[SpaceKraken/HOI4-Validator](https://github.com/SpaceKraken/HOI4-Validator)）：.NET CLI/图形校验器；老牌 [Kaiserreich/HOI4-Validator](https://github.com/Kaiserreich/HOI4-Validator) 已弃用、README 明示 replaced by CWTools。
- 集成：Python/PyQt6 侧不自己写解析器；二选一：LSP 子进程对接（实时提示）或包装 action CLI 的 `output.json`（批量报告）。
- 工作量 M；风险：CWTools 规则随版本滞后、大 mod LSP 首次缓存慢。

## 2. IRIS

- HOI4 语境下 IRIS = 二次元架空地图 **mod**（Steam 创意工坊《【Blossoms Blaze/華灼】~IRIS~ 九色堇之心》id=2739911713；[Skymods](https://hearts-of-iron-4.smods.ru/archives/36699)；[ztz233/Project_IRIS](https://github.com/ztz233/Project_IRIS)），**不是可集成库**。
- 结论：不排期；除非目标是把该 mod 作为编辑器适配对象。若本意是「审查/解析库」，最接近的是 CWTools。

## 3. 大众脸（肖像生成）

- 可行：StyleGAN2-ADA（[NVIDIA 页](https://nvlabs.github.io/stylegan2-ada-pytorch/)）生成人脸成熟；GFPGAN（[TencentARC/GFPGAN](https://github.com/TencentARC/GFPGAN)）修复/超分；社区已有 HOI4 画风 SDXL 模型/LoRA。
- HOI4 侧：`common/characters/*.txt` 的 `portrait` 引用 `gfx/interface/` sprite/dds（wiki Character modding）；导出需 dds 转换（[maldun/hoi4_converter](https://github.com/maldun/hoi4_converter)）。
- **许可硬约束**：FFHQ 数据集 CC BY-NC-SA（非商用）；StyleGAN2-ADA 权重 NVIDIA Source Code License-NC；GFPGAN 仓库无标准许可声明。→ 只做「非商业、本地生成」版。
- 成本：模型 100MB–1GB+、GPU 优先、torch/onnxruntime 依赖重、产出需人工筛选。
- 结论：P1 做本地生成版 M–L。

## 4. 电台/广播（Radio OGG 生成）

- HOI4 音乐/广播为 `.ogg`（Vorbis），经 `music.txt`/音乐电台条目引用（wiki Music modding；`plays an audio track` effect 要求歌曲在某 music station 中定义）。
- 低档（S，强烈建议）：OGG 打包/替换 + 语音广播（TTS）——ffmpeg 转码 + music.txt 模板。
- TTS：`edge-tts`（[rany2/edge-tts](https://github.com/rany2/edge-tts)，免 key 免费但在线灰色地带）或 `piper`（[rhasspy/piper](https://github.com/rhasspy/piper)，本地开源离线）。
- 高档（不建议 P1 自建）：自动生成完整背景音乐（MusicGen/Suno 等重型或付费）。

## 5. 批量填鸭（AOR）

- 术语歧义：「AOR」最常见 = **赤色极光 mod**（[Skymods Aurora of Red](https://hearts-of-iron-4.smods.ru/archives/49284)、[知乎](https://zhuanlan.zhihu.com/p/685073026)）；字面「Area of Responsibility（责任区）」是 HOI4 **运行时 UI**（Garrison Area / Fallback Line 热键），**不落盘成 mod 文件**。
- mod 侧能表达的是起始军队与起始战役计划（`history/countries/*.txt` 的 OOB）。若按「部署区批量分配」做：批量写 `add_army` + 起始战役计划，需地图拓扑数据（state→province、相邻、坐标），且无游戏运行时无法闭环校验。
- 结论：先澄清术语；部署区分配 M–L，纯模板生成 S。

## 排期建议

1. H4MPS：先澄清词义；审查能力用 CWTools（LSP/CLI）承接，M，价值高。
2. IRIS：澄清后大概率砍掉，不排期。
3. 大众脸：本地生成版 M–L，须限定非商用许可。
4. 电台 OGG：先做 S 档（打包/转码 + edge-tts/Piper 语音），音乐生成另议。
5. AOR：先澄清术语，澄清后评估 M–L 地图数据成本。
