3. `region_editor_dialog.py`：尺寸 → 1440×900；加多选按钮；选区反馈统一黄色高亮 + 数量提示；
   「✕ 清空选区」；操作按钮文案「用选区」。

## 6.2 遗留问题 4 项（2026-08-15）

1. **地图矢量轮廓填充 v2（`map_fill.py`）**：省 ID 矩阵全局提取闭合轮廓多边形
   （有向单位边 + 左转规则链接 = Marching Squares 等价实现，正确处理鞍点/孔洞/多连通）
   + Douglas-Peucker 简化（批量向量化，全图 15120 环构建 2.7s）+ 磁盘缓存
   （`.runtime/map_fill/`）。`map_canvas.py` 的 `VectorBaseItem` 在缩放 ≥ 阈值时用
   矢量多边形填充替代位图底图；实测 30× 视口 11.7ms/帧、90× 5.7ms/帧。
   ⚠️ item paint 里 `clipBoundingRect()`/`option.exposedRect` 在 grab 场景不可靠，
   `_paint_fill` 用设备尺寸反变换算可见范围。
2. **OOB 放置窗口迁移 MapCanvas**：`oob_map_editor.py` 移除自绘 MapView；给 `map_canvas.py`
   加 `left_clicked`/`right_clicked`/`hover_moved` 信号 + `add_painter` 前景绘制钩子。
   ⚠️ PyQt6 `QPainter.drawPixmap` **没有 (float, float, QPixmap) 重载**，必须用
   `drawPixmap(QPointF(...), pixmap)`。
3. **阈值/防抖可调**：settings.json 新增 `map_zoom_threshold`（默认 2.5）与
   `map_zoom_settle_ms`（默认 300，早期 1000），`read_map_settings()` 读取。
4. **Scenario Forge 移植 4 子项**：
   - `overlay_rules.py`：规则分层 + delta 增量模型（vanilla 只读层 + mod 覆盖层；
     new/override/identical + 质量分级 + difflib 行级报告）；`/api/overlay_report` + MCP。
   - `icon_manifest.py`：扫描 mod+游戏整树 `*.gfx` spriteType；`/api/icon_manifest` + MCP。
   - `unit_counter_library.py`：从游戏 `gfx/interface/counters/*/onmap_*.dds` 提取转 PNG
     + manifest.json；真实游戏 **448 个标牌 2.6s 导入**。
   - 测试：OverlayRulesTest / IconManifestTest / UnitCounterLibraryTest /
     MapCanvasExtensionsTest / OobMapEditorSmokeTest 全绿。

## 6.3 地图画布渲染缓存优化（2026-08-15，用户拍板「不牺牲锐利度」）

1. **省级 QPainterPath LRU 缓存**：`_path_cache`（OrderedDict，上限 2048）+ `_pid_loop_off`
   环索引；每省一条 even-odd 多环 path，只在首次绘制时构建。
2. **视口栅格瓦片缓存**：按缩放档 + 可见区域渲染一次到离屏位图（外扩 0.5 倍，上限 4096 防爆）；
   平移命中缓存区时整帧纯 blit；瓦片设备像素对齐，1:1 拷贝无重采样模糊。
3. **边界线烘焙进瓦片 + numpy 像素混合（本轮真凶）**：
   - 根因：`map_vector` 合并后的边界线段横跨整幅地图，Qt 光栅器对长线段描边 ~1ms/千像素，
     旧 drawForeground **每帧整条绘制**，30× 平移单帧 **3.7~8.5 秒**。
   - 修复：`_select_borders`（相交筛选 + 轴对齐几何裁剪）+ `_bake_borders`
     （相接段 numpy 归并，1px 描边预乘 alpha 混合进瓦片像素，小端 0xAARRGGBB；
     大端回退 QPainter）。bake 实测 **7.9ms**（原 2.8s）。
   - 实测：缩放档 4.95~6.96ms/帧（瓦片命中 20/20），30× 平移模拟 **21.7ms/帧**
     （旧实现 3.7~8.5s/帧，~300 倍）。
   - ⚠️ `scale(s,s).translate(-rx0,-ry0)` = 点先平移后缩放；瓦片尺寸必须按设备像素（w×dpr）；
     `_blend_border` 依赖小端 0xAARRGGBB。
4. **滚轮预览缩放**：滚动期间进入预览模式，把已渲染瓦片当位图实时缩放（零矢量重绘，
   实测 4.8~5.4ms/帧）；停止 `map_zoom_settle_ms`（默认 1000→300）后重渲染高质量瓦片。
5. **手型合并点选语义**：`MODE_PAN` 同时具备点选/悬停；`MODE_POINT` 保留兼容；
   两个地图对话框去掉「👆 点选」按钮。
   ⚠️ `QTest.mouseMove` 不可靠（事件不带按键状态；offscreen 多窗口时事件不投递）——
   悬停模拟统一用 `_send_move` helper。
6. **瓦片位置跟随修复**：`_blit_tile` 须把场景区原点经 `worldTransform().map()` 投影到
   当前视图设备位置再 1:1 拷贝；否则平移时色块钉在原地。回归测试
   `test_tile_follows_pan` / `test_tile_follows_preview_zoom`。
7. **初始视野放大去留白**：`fit_map(factor=1.0)` 加放大系数；`map_initial_zoom`（默认 1.3，
   clamp 1.0~4.0）；region 编辑器原先无初始视野一并修复。
8. **两层醒目选中高亮 + 删除悬停信息展示**：hover_item（z=40，青色 `HOVER_COLOR=(80,200,255)`
   alpha 130，LRU 16）；选中黄色层 z=50；悬停不再刷新右侧信息；点选 = 单选。
