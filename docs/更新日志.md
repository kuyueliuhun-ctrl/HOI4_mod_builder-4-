## 0.7.0（2026-08-31）

两大新功能（多 Mod 冲突检查、子 Mod 制作）+ 一次全面的性能与安全修复。对应迭代 6.85 ~ 6.91。

### 新功能：多 Mod 冲突检查
- 「工具 → ⚔ 多Mod冲突检查」：选择一个播放集（读取游戏启动器数据库 `launcher-v2.sqlite`，或回退 `dlc_load.json` 最近启动集），一次性扫描整个播放集的冲突并分级报告：
  - **L0 元信息**：重复注册（同内容目录/同创意工坊 ID）、缺失依赖、依赖环、游戏版本不匹配；
  - **L1 文件遮蔽**：同相对路径整文件覆盖（靠后者胜）；`replace_path` 清空语义（其他 mod / 原版在该前缀下的文件全部失效——最常见的"隐形冲突"）；
  - **L2 实体 id**：跨 mod 同域同 id（国策/精神/科技/角色/决议/事件/动态修正等 8 域），区分"后者覆盖"与"重复注册"两种语义；
  - **L3 本地化键**：同语言节内跨 mod 同 key。
- 报告三级分组（严重度→类型→条目）、双击跳转文件、导出 JSON / HTML；「含原版层」「本地化/实体扫描」可选开关。
- 解析失败文件自动跳过并计数，不中断扫描；每类上限 500 条防卡顿。

### 新功能：子 Mod 制作
- 「工具 → 🧩 子Mod制作向导」：三步创建子 mod（选播放集 → 勾选依附的底层 mod → 填名称/版本/标签），生成**真实可玩可发布的独立 mod**（dependencies 自动写入底层 mod 名，支持中文/空格名转义）。
- **子 mod 模式**：激活后编辑器读取范围覆盖整个播放集（子 mod → 底层 mod 们 → 原版，同路径取最高层），而所有新建/保存**恒定写入子 mod**。
- 文件树合并视图：底层文件带〔底层〕标识；从底层文件打开编辑并保存时弹窗三选——**保存到子mod（覆盖副本）/ 另存为 / 取消**；copy_up 操作同样需确认。
- 状态栏常驻模式徽标；模式随 settings.json 持久化，重启自动恢复；退出后恢复传统单 mod 语义。
- 典型用途：为汉化/魔改/增量补丁维护独立小 mod，不动创意工坊原 mod（尤其适合 workshop 只读目录）。

### 新功能：MCP 外部接口同步
- 新增 6 个 MCP 工具：`playset_list`、`playset_conflict_scan`、`submod_status`、`submod_create`、`submod_activate`、`submod_exit`。
- 外置 Agent 可完整驱动两个功能：创建并激活子 mod 后，同一进程内的所有读写路由自动经层栈生效；settings 持久化与 GUI 互通（读改写仅合并 submod 字段）。

### 性能（评估修复 P0）
- 解析器 O(n²) 线性化：530KB 国策文件打开从 **36 秒 → 0.083 秒**；81 个原版国策文件全量解析 2.58 秒；线性化有翻倍耗时基准契约防回退。
- 实体扫描去 O(m²)：嵌套块去重改单调栈保序；`find_block_range` 等定位器单遍 O(n)。

### 正确性与数据安全（评估修复 P0/P1）
- 修复存量破坏性 bug：保存多顶层块文件（如 ideas/gfx 类）不再被整体错误包进 `focus = {}` 外壳；注释/空行/缩进按原文行保真；无改动保存不写盘（字节级一致）；外部修改（mtime）检测后才覆盖。
- 写安全：只读文件写入后恢复原权限；undo 快照 64MB 字节预算防内存膨胀；「读→改→写」路径严格解码——坏编码文件（如 GBK）写回前中止，原文件不动。
- 缓存精确失效：保存某类文件只失效对应缓存，不再全库重扫。

### 体验与杂项（P2）
- 本地化缺失时回退英文显示（mod 名称/描述不再空白）。
- 州历史数字 id 重复检查；国家 tag 全局索引（跨目录命中）。
- 树编辑器回车循环搜索（回车跳下一个匹配 + 进度提示）。

### 工程与发布
- `launcher.py --verify`：一键 8 项契约验证（编译/ruff/单元测试/写入纪律/四层依赖/MCP/行数预算/UI 缺口），Windows + WSL 双端全绿；测试累计 880+ 条。
- 便携版打包：解压即用免安装（`tools/build_portable.py`）。
