# 便携版打包（无需预装 Python/Qt）

> 便携版 = 在构建机上一次打包，生成一个自带 Python 和全部依赖的文件夹；
> 最终用户解压后直接运行，不需要预装 Python，也不需要单独安装 Qt。

## 什么时候用

- 给不熟悉 Python 的玩家/朋友分发；
- 目标电脑没有 Python，或不想让用户安装运行时；
- 想固定一个已验证可运行的依赖版本；
- 想把项目内的 `.venv` 替换为“随项目携带、解压即用”的便携运行时。

## 当前支持范围

- ✅ **Windows 便携版**：完整复制当前 Windows Python 安装目录 + 安装依赖。
- ✅ **Linux/WSL 便携版**：下载 python-build-standalone 便携 Python + 安装依赖。
- 两者可同时放在项目 `portable/` 下，`launcher.py` 会自动按当前平台选择。

## 在当前项目生成便携运行时（替换 `.venv`）

```bat
:: Windows：生成 portable\win
cd /d E:\hearts_of_iron_builder
python tools\build_portable.py --runtime-only --platform win
```

```bash
# Linux/WSL：生成 portable/linux
cd /mnt/e/hearts_of_iron_builder
python3 tools/build_portable.py --runtime-only --platform linux
```

生成后目录结构：

```text
portable\
├── win\                      Windows 便携 Python
│   ├── python.exe
│   ├── Lib\site-packages\    PyQt6/numpy/Pillow/mcp
│   └── ...
└── linux\                    Linux/WSL 便携 Python
    ├── bin\python
    ├── lib\python3.14\site-packages\
    └── ...
```

`launcher.py` 检测到对应平台的便携 Python 后会自动进入便携模式，
不再创建 venv，也不再要求系统 Python。

## 生成完整发布包

```bat
:: Windows 完整发布包
python tools\build_portable.py --zip
```

```bash
# Linux/WSL 完整发布包
python3 tools/build_portable.py --zip --platform linux
```

生成目录：

```text
dist\HOI4编辑器-便携版\
├── portable\python\         便携 Python + PyQt6/numpy/Pillow/mcp
├── src\                     程序源码
├── docs\                    文档
├── templates\               模板
├── translations\            本地化
├── tools\                   工具与契约脚本
├── launcher.py
├── 启动.bat                   Windows 双击
├── 启动.sh                    Linux/WSL 运行
└── README-便携版.txt
```

## 最终用户使用

1. 解压 `HOI4编辑器-便携版.zip`；
2. Windows 双击 `启动.bat`；Linux/WSL 执行 `bash 启动.sh`；
3. 在设置里填写游戏路径和 Mod 路径；
4. 开始编辑。

不需要安装 Python，也不需要安装 Qt。

## 原理

1. Windows：读取当前 Python 安装根目录（`sys.base_prefix`），整体复制到
   `portable\win\`；
2. Linux/WSL：从 python-build-standalone 下载 3.14 x86_64 便携 Python，
   解压后复制到 `portable/linux/`（已处理 Windows 挂载盘上的符号链接/大小写冲突）；
3. 使用便携 Python 的 pip 安装当前平台依赖（PyQt6 自带 Qt）；
4. `launcher.py` 检测到 `portable/win/python.exe` 或 `portable/linux/bin/python`
   后自动进入便携模式。

## 注意事项

- 打包机必须能正常联网安装依赖；
- Windows 打包不要在 venv 解释器里执行脚本（脚本会自动定位基础 Python 安装目录）；
- Linux 便携包因包含完整 Python 与依赖，体积较大（数百 MB）；
- `portable/` 已加入 `.gitignore`，不会提交进 Git；
- `settings.json` 是个人路径配置，**不会**被打进便携包。
