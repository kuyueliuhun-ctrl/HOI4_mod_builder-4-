# 便携版打包（无需预装 Python/Qt）

> 便携版 = 在发布机上一次打包，生成一个自带 Python 和全部依赖的文件夹；
> 最终用户解压后直接运行，不需要预装 Python，也不需要单独安装 Qt。

## 什么时候用

- 给不熟悉 Python 的玩家/朋友分发；
- 目标电脑没有 Python，或不想让用户安装运行时；
- 想固定一个已验证可运行的依赖版本。

## 当前支持范围

- ✅ **Windows 便携版**：完整复制当前 Windows Python 安装目录 + 安装依赖 + 复制项目文件。
- ⏳ **Linux/WSL 便携版**：暂未实现；Linux/WSL 用户继续使用 `launcher.py` 自动创建虚拟环境。

## 在 Windows 构建机上打包

```bat
cd /d E:\hearts_of_iron_builder
python tools\build_portable.py
```

生成目录：

```text
dist\HOI4编辑器-便携版\
├── portable\python\         便携 Python + PyQt6/numpy/Pillow/mcp
├── src\                     程序源码
├── docs\                    文档
├── templates\               模板
├── translations\            本地化
├── tools\                   工具与契约脚本
├── launcher.py
├── 启动.bat                  解压后双击这个
└── README-便携版.txt
```

如果需要同时生成 zip：

```bat
python tools\build_portable.py --zip
```

自定义输出目录：

```bat
python tools\build_portable.py --output D:\out\HOI4编辑器
```

## 最终用户使用

1. 解压 `HOI4编辑器-便携版.zip`；
2. 双击 `启动.bat`；
3. 在设置里填写游戏路径和 Mod 路径；
4. 开始编辑。

不需要安装 Python，也不需要安装 Qt。

## 原理

1. `tools/build_portable.py` 读取当前 Python 的安装根目录（`sys.base_prefix`），
   整体复制到 `portable\python\`；
2. 使用包内 `python.exe -m pip install -r requirements.txt` 安装依赖；
   PyQt6 的安装包自带 Qt 运行库；
3. 复制 `src/`、`docs/`、`templates/`、`translations/`、`tools/` 等运行所需目录；
4. 生成专属 `启动.bat`，直接调用 `portable\python\python.exe launcher.py`；
5. `launcher.py` 检测到 `portable/python/python.exe` 后自动进入**便携模式**，
   不再要求系统 Python，也不再创建 venv。

## 注意事项

- 打包机必须能正常联网安装依赖；
- 不要在 venv 解释器里执行打包脚本（脚本会自动定位基础 Python 安装目录）；
- 便携包体积通常较大（数百 MB），适合作为 Release 附件，不适合提交进 Git；
- `settings.json` 是个人路径配置，**不会**被打进便携包。
