> 建立：2026-08-19（随 P3 整合批次产出）
> 范围：覆盖本程序**全部功能**（含各类 UI 已有的功能）与**实现方式**（模块/数据流/写入纪律）。

## 1. 概述与技术栈

| 项 | 说明 |
| --- | --- |
| 定位 | Windows 桌面 HOI4 Mod 编辑器：直接读写 mod 目录下游戏脚本（`.txt/.gfx/.yml/.mod/.csv`），并带地图可视化 |
| 语言/框架 | Python 3.8（启动用 `.venv`）+ PyQt6；系统 Python 3.13 用于开发/测试（**必须双版本兼容**） |
| 入口 | `src/main.py`（`启动.bat` / `启动.sh` 均指向它）；驱动 UI 形态的配置在根 `settings.json` |
| 分层纪律 | AGENTS §4.9 四层分离：算法层 ← 绘图层 ← UI 层 ← 信号槽层，单向依赖，`tools/check_layer_deps.py` 门禁 |
| 写入纪律 | mod 内容文件一律走 `write_utils.atomic_write_text` / `icon_ops.write_file_utf8`（原子写 + BOM 拒绝 + 撤销快照）；本地化 `.yml` 例外 `utf-8-sig + allow_bom` |
| 验证 | `tools/verify_contracts.py`（语法编译 + 契约测试 + 写入纪律扫描 + 四层依赖）双版本全绿 |

## 3. 工作台与通用编辑（UI 功能清单）

### 3.1 工作台（94 类内容类型）

- **类型列表分组**：有专用编辑器的类型（`SPECIAL_TYPE_KEYS`：focus/tech/initial_oob/bop/AI*…）置顶，其余在分隔线下走通用树编辑。
- **文件模式**：类型 → 文件列表 → 实体提取（`_quick_*_scan`/`entity_scanner`）；双击按路径路由到专用编辑器（OOB→设计器、BOP→BOP 工作台、AI→AI 编辑器等）。
- **无文件模式**：国家选择（**纯选择不写文件**，`_on_select_country`）、下方展示当前国家、「国家设置（复制/创建）」为显式写操作。
- **实现**：`workbench.py`(WorkbenchDock) + `content_types.py` + `entity_scanner.py` + `workbench_nofile_country` 逻辑；路由在 `app_routes.py`/`main_window.py`。

### 3.2 通用 PDX 树形编辑器

- 节点树展示任意脚本；新增/编辑/删除节点；支持词条/模板/自定义语句搜索；原始 PDX 高级模式。
- 所有内容类型在没有专用编辑器时的默认编辑入口；写回走原子写 + 撤销快照。
- **实现**：`generic_tree_editor.py` + `tree_node.py`/`pdx_parser.py` + `node_edit_dialog.py`。

### 3.3 国策/科技树画布

- 国策树像游戏内一样绘制；文件模式（读分文件/完整树）与无文件模式（画树后产出代码）。
- 节点卡片 + 连线 + 图标上传（本地/在线/历史）；`tech_view` 科技树（folder 分组、path 连线、BFS 布局）。
- 实体画廊（`EntityGalleryControllerMixin`）；国策顺序编辑器（`focus_order_picker.py`：点选顺序、黑框红底角标、右键调整/删除并联动后续依赖）。
- **实现**：`focus_view.py`(1188 行，已按四层拆分) + `focus_algo.py`(算法) + `focus_render.py`(绘图) + `focus_view_ctrl.py`(控制器) + `focus_processor.py` + `focus_renderer.py` + `tech_view.py`。

### 3.4 API 覆盖外的通用类型

工作台其余通用类型（共 94 类，含 科技装备/学说/建筑/资源/占领法/事件/决议/阴谋/行动/超事件/MIO/勋章/科学家特质/血腥行动…）统一走树编辑器；模板库已为这些类别提供基础(file)+项目(node)模板。

## 4. 专用编辑器（各类 UI 已有功能明细）

### 4.1 师编制编辑器 v2（Division Editor）

| UI 功能 | 实现 |
| --- | --- |
| 顶部：模板下拉(含部署数)/改名/🔒锁定/新建/复制/删除/🗺地编/💾保存 | `division_editor.py` |

| 军种识别自动拉起（含海军→舰艇设计器、空军→飞机设计器） | `oob_loader.detect_oob_kinds` + `open_oob_designer` |
| 部署引用/模板机制 | 保存走原子写；OOB 海军/空军 `version_name` 解析（见 §6.3 遗留） |

### 4.2 舰艇/飞机/坦克设计器

| UI 功能 | 实现 |
| --- | --- |
| 顶部国家/设计下拉、改名、新建/复制/删除、保存（原版自动落 mod） | `ship/plane/tank_design_dialog.py` + `state_build_ops.ensure_file_in_mod` |
| 槽位网格（固定槽中文名/模块缩写/空槽＋/必装🔒锁定槽；飞机 5 列/舰艇 6 列） | `designer_common.ModulePickerDialog`（按 allowed categories 过滤） |
| 空配件设计橙色提示；「同款 N 国」+ 同步到所有同款 | `_block_map`(单行内联兼容) + `_tag_of/_save_path` |
| 属性估算面板（基础/战斗/其他）与花费 | `*_design_stats`（hull/airframe/chassis 基础 + 模块 addΣ × multiply 累积） |
| 模板「存为模板/模板新建」 | `design_template.py`（独立 `design_templates/`，普通模板搜索器搜不到） |

### 4.3 OOB 地图放置

- 选择编制 → 点选地块放置部队；`MapCanvas` 扩展点 `left_clicked/right_clicked/hover_moved` + `add_painter` 前景钩子（兵牌恒定屏幕大小）。
- 单例缓存 `get_map_data/get_state_data`（按 mod+game 键）。

### 4.4 力量平衡（Balance of Power）工作台

- 深色历史 UI：米白标题、金色描边、动作行、状态圆点、右上角关闭。
- 滑块编辑 `initial_value`；势力与修正页（side/range/modifier）；动作列表（费用/方向）。
- 本地化自动显示中文（去 `£BoP_*` token、解析 `$KEY$`）；「✏ 编辑定义」打开对应文件树编辑器定位节点。
- 保存走 `ensure_file_in_mod` + 原子写。**实现**：`bop_loader.py` + `bop_editor_dialog.py`。

### 4.5 AI 内容编辑器（固定侧边栏专用 UI）

- 公共组件 `ai_ui_common.py`：`EntityListSidebar`(固定 300px、无横向滚动) + `KeyValueTableEditor` + `ScriptBlockEditorDialog`（复用 NodeEditDialog/TemplateDialog/TermDialog，面包屑进入子块）。
- 类型与写回：战略计划(国策顺序)、战略倾向、师模板(target_template)、装备(target_variant)、海军(三页签)、派系战区(地图联动)、区域、科研权重——全部实体级 CRUD（insert/delete/rename/duplicate），未知字段保留，走 `ensure_file_in_mod` + 原子写。

### 4.6 角色专用编辑器

- 只替换 name/portraits 区域、**保留 roles**（country_leader/advisor/leader 等）；字符级块定位 `split_char_blocks` + `render_character_block`（raw 正则替换）。
- **实现**：`character_data.py` + `character_editor_dialog.py`；工作台「👤 角色编辑器」入口。

### 4.7 本地化编辑体系

| UI 功能 | 实现 |
| --- | --- |
| 全量词条浏览/搜索/新增/编辑/删除、只看修正 | `localisation_editor_dialog.py` + `localisation_editor_data.py`（`LOC_CATEGORIES` 分类下拉：国策/决议/事件/理念/科技/修正/人物/界面/其他） |
| 批量补写缺失 + 多语言（默认中文、英文仅选择才显示；选英文 `--中文`→`--英文`） | `batch_fill_missing_loc` / `find_missing_loc_keys`（默认 `simp_chinese`） |
| 各编辑器右键快速本地化小窗（BOP 含名称+描述） | `quick_loc_menu.py` + `quick_localisation_edit.py`（`desc_edit` 仅当传 `desc_key`） |
| 实体配套资源工作台 | `entity_resource_data.py` + `entity_resource_dialog.py`：按文件/国家/全 mod 列出实体，表格批量本地化、上传图标（复用 `icon_ops`）、一键补全缺失光效 GFX（已有不改，游戏内素材），含「自动补光效」选项 |

### 4.8 内容生成器工作台

`content_generator_dialog.py` 统一入口，调用 `toolgen` 生成器：country / ideas / ideology / character / general / focus（树+本地化+图标 GFX 文本）。规则：任务选择 → 生成 → 复制/保存；保存走原子写，本地化 `utf-8-sig allow_bom`。

- **系统模板**：`templates/系统模板/<类别>/基础模板.txt`(file) + `项目模板.txt`(node)，67 个类别；分类经 `template_dialog.CATEGORIES` 接入。2026-08-19 补齐：`country_history`（原空）、`新闻`、`战略区域`、`补给区域`、`初始部队/完整版模板`（含命名组/海军/空军/开局生产，格式对照游戏本体）。
- **国家历史模板**：`templates/country_history/`（set_politics/set_popularities/set_technology/recruit_character/add_ideas…）。
- **词条库**：`term_registry.py` 管理，`TERM_FILES` 末尾加载 `translations/qiqi_*.json`（共 ~3100 条：主库 1887 + modcode 939 + diplo 11 + tfr 50 + tno 210），**同键冲突 QIUQI 最后加载胜出**；`translate_key` 链：custom_statements → command_dict → loc_cache → term_registry（最低回退）。
