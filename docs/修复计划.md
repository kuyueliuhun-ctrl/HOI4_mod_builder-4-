### 2b. 行数预算门禁（防存量名单变长）

新建 `tools/check_file_budget.py`（并入 verify 第 5 步）：

```python
"""行数预算：>BUDGET 行的 src/*.py 必须在白名单内；白名单外超限即失败。"""
import json, os, sys

BUDGET = 1200
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
ALLOWLIST = os.path.join(ROOT, "tools", "file_budget_allowlist.json")
# 初始白名单 = 当前 8 个存量文件（相对 src/ 路径）

def main():
    with open(ALLOWLIST, encoding="utf-8") as f:
        allow = set(json.load(f))
    bad, warn = [], []
    srcdir = os.path.join(ROOT, "src")
    for fn in os.listdir(srcdir):
        if not fn.endswith(".py"):
            continue
        p = os.path.join(srcdir, fn)
        n = sum(1 for _ in open(p, encoding="utf-8", errors="replace"))
        if n <= BUDGET:
            continue
        rel = "src/" + fn
        (warn if rel in allow else bad).append("%s %d 行" % (rel, n))
    for w in warn:
        print("  [白名单] %s（拆分后从白名单移除）" % w)
    for b in bad:
        print("  [超限] %s（> %d 行且不在白名单）" % (b, BUDGET))
    return 1 if bad else 0

if __name__ == "__main__":
    sys.exit(main())
```

- 初始白名单写入 `tools/file_budget_allowlist.json`（main_window / ai_loader /
  oob_loader / bop_editor_dialog / generic_tree_editor / advisor_assign_dialog /
  map_canvas / focus_view，加 `focus_view_ctrl.py` 共 9 项）；
- F5 每拆完一个文件即从白名单移除，白名单**只减不增**（增补需在 AGENTS 登记理由）。
