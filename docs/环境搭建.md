# 环境搭建（F7）

> 项目目标环境：**Python 3.14+**（Windows `.venv` 3.14.5 / WSL 3.14.4 / CI 3.14）。
> 旧 Python 3.8 已退役；原 `.venv` 备份 `.venv_py38_backup` 已于 2025-08-25 清理（如需要可重建）。

## 1. Windows（推荐启动方式）

1. 安装 Python 3.14（如 `py -3.14` 可用），确保 `py` launcher 存在。
2. 创建并安装依赖：
   ```bat
   py -3.14 -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
3. 启动：
   ```bat
   启动.bat
   ```
4. 验证：
   ```bat
   .venv\Scripts\python.exe -X utf8 tools/verify_contracts.py
   ```

## 2. WSL / Linux

1. 使用系统 Python 3.14：
   ```bash
   python3 -m venv /root/hoi4_builder_venv
   /root/hoi4_builder_venv/bin/pip install -r requirements-wsl.txt
   ```
2. 无头运行：
   ```bash
   QT_QPA_PLATFORM=offscreen /root/hoi4_builder_venv/bin/python -X utf8 tools/verify_contracts.py
   ```
3. 启动 GUI（若 WSLg 可用）：
   ```bash
   bash 启动.sh
   ```

## 3. 一键脚本

- Windows：`setup.bat`（创建 .venv + 安装 requirements + verify）
- WSL/Linux：`setup.sh`（创建 /root/hoi4_builder_venv + 安装 requirements-wsl + verify）

## 4. 常见坑索引

- 控制台 GBK：跑 Python 加 `-X utf8`（Windows 中文路径/print emoji 会崩）。
- offscreen 字体警告可忽略；真实窗口用 `QT_QPA_PLATFORM=windows`。
- 契约测试双版本：Windows `.venv` 与 WSL `/root/hoi4_builder_venv` 都要跑。
- 写入纪律：mod 内容文件必须走 `write_utils.atomic_write_text`；不要直接 `open(..., "w")`。
- 四层分离：算法/绘图层禁止反向依赖 UI/信号槽层，`tools/check_layer_deps.py`。
- 真实数据冒烟：`E:\mods\3350890356`（Windows）或 `/mnt/e/mods/3350890356`（WSL）。
- UI 缺口：改专用 UI 后跑 `ui_gap_probe.py --max-files 0`；本地 verify 已内置轻量探针。
