# 学说识图结果（DeepSeek 视觉模型）

作为HOI4模组编辑器开发者，以下是基于两张截图对军事学说（Doctrine）界面的详细识图分析。注意：截图中的具体加成数值为0或20%，但我不会臆造界面中未直接显示的字段。

---

### 1. 界面整体布局

**图1（学说总览界面）：**
*   **顶部：** 四个并排的学说大类标签页（Tab），当前“陆军学说”处于选中高亮状态。
*   **中部偏上：** 顶部正中央显示当前选定的学说流派（焦点图标+标题“人海突击”）。
*   **中部主体：** 四个并排的竖长条形大面板（代表学说的四个分支），每个面板内包含图标、标题、当前已激活的学说条（绿色横幅）、加成数值和花费数值。
*   **背景：** 暗灰色纹理背景，为UI提供对比度。无左侧、右侧侧边栏。

**图2（学说详细树状图界面）：**
*   **顶部：** 面板顶部的流派徽章（交叉双剑/鹰徽），下方是分支标题“步兵”，接着是当前选中的学说图标、加成/花费标识，以及激活的学说名称“机动步兵”（绿色横幅）。
*   **中部主体：** 垂直的树状结构（技能树/分支树），包含中间主干线（带有数值100-500）和左右交错分布的分支节点（I到V）。

---

### 3. 元素层级与交互关系

*   **层级结构：** 军事学说系统采用了 **“大类 (Tab) → 流派 (Doctrine Group) → 分支 (Branch) → 节点 (Node)”** 的层级结构。
*   **交互逻辑：**
    1.  点击顶部的“陆军学说”Tab，会展开陆军的各个学说流派（显示“人海突击”为当前选中的流派）。
    2.  点击顶部的“人海突击”流派标题，或者直接进入流派界面，会看到图1中的四个分支面板（步兵、炮兵与支援、装甲、作战）。
    3.  在图1中，**点击任意一个分支面板**（例如点击“步兵”面板的空白处或图标），会**打开**该分支的详细树状图界面（即图2）。
    4.  在图2中，展示了该分支的树状发展路径。主干线下方是 I 到 V 的节点。玩家需要沿着主干线（花费100、200、300、400、500陆军经验值）逐级解锁左侧（I, III, V）和右侧（II, IV）的节点。

---

### 4. 图标、状态、数值、花费、加成等细节

**图1（总览界面）：**
*   **流派图标：** 顶部“人海突击”图标为带翅膀的金色皇冠/鹰徽。
*   **分支图标：** 四个面板的顶部图标依次为：士兵（步兵）、火炮（炮兵与支援）、坦克/装甲（装甲）、五角星（作战）。
*   **状态标识：** 绿色横幅代表当前“已激活/已选择”的学说。该学说在分支内有对应的节点。
*   **数值与花费：**
    *   **加成（左侧）：** `+20%`，带星号图标，代表该学说提供的某种加成（如组织度或计划速度），但图片中未显示具体属性名称。
    *   **花费（右侧）：** `0`，图标疑似为“陆军经验值”或“指挥点数”，这里显示为0，表示此分支当前已花费的经验值或当前无需额外花费。

**图2（详细界面）：**
*   **状态图标：** 顶部圆形图标是一个带箭头的靴子/旋风图案（代表“机动”属性），左侧有星号+20%加成，右侧有0花费。
*   **树状图节点图标：** 左右两侧的节点图标均为国际象棋中的棋子（如“兵”/“马”形状），这通常代表该学说的战术战术/兵种强化塔。
*   **数值与花费：**
    *   **主干线数值：** `100`、`200`、`300`、`400`、`500`。这些是购买/解锁相邻左右节点所需的**陆军经验值（Army XP）**成本。即解锁节点I需要100点，解锁节点II需要200点，以此类推。
    *   **节点层级：** 罗马数字 `I` 到 `V` 标识了该分支内的五个研究层级（Rank），玩家需要按顺序从上往下推进。
*   **状态细节：** 当前界面显示“机动步兵”处于选中状态（绿色横幅高亮），且顶部加成显示为+20%，说明这是I级节点（花费100）中的初始/已解锁学说。玩家尚未解锁II、III、IV、V级节点（节点呈暗色未激活状态）。

---

**给模组编辑开发者的提示：** 
这些界面元素内部逻辑对应于 `common/doctrines` 文件夹中的文件。绿色的“机动步兵”横幅是 `decision` 或当前的 `doctrine` 选择状态。树状图上的“100-500”数值是 `cost` （陆军经验值）。分支树中的 I-V 节点对应 `tiers`，其中左侧和右侧节点是该 tier 下的两个互相竞争/可选择的选项。
